Build the world's best football player search engine where football fans can instantly search any player and access accurate, fast, beautifully presented career statistics, comparisons, trophies, rankings and AI-powered football insights.

The database is the heart of the application.

The Football API is NOT the application's source of truth.

The application should never depend directly on the API during page rendering.
